# Lancer 简易车卡器

《枪骑兵》（Lancer）中文车卡器，纯前端、无需安装：直接双击 `index.html` 用浏览器打开即可。也可以运行 `node tools/serve.js` 后访问 http://localhost:8765 。

术语以《枪骑兵》核心规则书 v3.5 中文版为准，并收录了《所有扩展.pdf》及补充资料中的扩展内容。

## 使用

### 建卡方式

第一次打开或点「新建」时，可以选择：

- **引导式车卡**：按规则书顺序一步步完成（起始等级 → 资料 → 背景 → 触发 → 机甲技能 → 天赋 → 牌照 → 核心奖励 → 驾驶员装备 → 骨架 → 武器与系统 → 总检查），每步附规则讲解，并实时检查点数。LL0 会自动跳过牌照和核心奖励。中途关掉网页，下次会回到原来的步骤。
- **自定义车卡**：直接打开完整编辑器（驾驶员 / 等级成长 / 机甲 / 角色卡四个页面）。
- 已有角色也可以点顶部「引导车卡」重新走一遍流程。

### 编辑器功能

- **规则检查**：右上角显示待处理项目（点数、牌照、SP、挂载点、AI 数量等）。
- **牌照内容**：等级成长页每个牌照都可展开「牌照内容」，查看 I、II、III 级分别解锁的骨架、变体骨架、武器、系统与改装，已解锁的等级会高亮。
- **天赋查找**：按中文、英文名称或效果关键词搜索，可只看已选。
- **骨架筛选**：机甲页的骨架选单与引导式「选择骨架」都可以按名称、特征搜索，按厂商、定位、来源（核心 / 扩展 / 变体）筛选，或只看可用的骨架。
- **系统搜索**：安装系统时可按名称或效果搜索。
- **驾驶员装备**：按装甲、武器、其他装备分组选择，防护服会自动改变驾驶员数值。
- **无视牌照限制**（「角色管理」菜单里）：给 GM 规划或特殊规则时用，所有骨架、装备、核心奖励都可选，页面会显示提示。

### 查询工具

- **术语库**：顶部「术语库」按钮打开，可搜索、按分类查看约 140 条规则术语（另自动并入全部标签说明与扩展规则）。页面正文中的术语会高亮，鼠标悬停显示含义，点击跳到术语库对应条目。多义词（如「强化」「反应」「结构」）只在规则意义下标记。
- **武器表**：顶部「武器表」按钮打开，列出全部 128 件机甲武器（含扩展、天赋武器与骨架内建武器）的来源牌照、尺寸、类型、射程、伤害、标签、SP 和完整效果。可搜索，按尺寸、类型、来源筛选，或只看当前角色可用的武器。

### 保存、导入与导出

- 角色自动保存在当前浏览器（localStorage）。换电脑或换浏览器前，请在「角色卡 / 导出」页导出 JSON。
- **导入**：「角色管理」菜单的「导入角色 JSON」、新建弹窗里的「导入已有角色」，或直接把 JSON 文件拖进页面。可以是单个角色、角色数组，或「备份全部角色」的文件。导入时会补齐缺的字段，找不到的天赋、装备等会略过并列出来。
- **导出**：角色卡页可下载驾驶员卡、机甲卡图片（按官方角色卡版式），复制文字角色卡，或下载 JSON。图片卡是固定版式的摘要，完整配置请保留 JSON。

## 扩展内容

来自《所有扩展.pdf》及后续补充截图，界面上带金色「扩展」标记。

- **天赋**（等级成长页「扩展天赋」一栏）：战场分析师、探勘者、偶像破坏者、读心者、爆破专家、系统管理员、演说家、家族禁卫、潘克拉蒂、黑拇指、太空民。
- **新授权骨架**（与其他牌照一样分 I–III 级解锁骨架和装备）：
  - IPS-N：基德、卡利班、郑、米切尔、法罗斯
  - SSC：白巫蛾、帝王蝶（HP 不因毅力提高）、阿特拉斯蛾、蛇目蝶、镰翅蛾
  - HORUS：狗头人、巫妖、幽灵、羽蛇
  - HA：吉尔伽美什、孙子、哈勃、为朝
- **变体骨架**（骨架选单中排在标准骨架下方；沿用标准骨架的牌照，该牌照 II 级即可使用，与标准骨架互斥）：因帕卡伊（黑胡子）、蒲公英（兰开斯特）、施托特贝克（雷利）、晶眼蝶（蚬蝶；PDF 误写为「蜘蝶」）、红门兰（黑巫蛾）、总督蝶（金斑蝶）、游骑兵（凤蝶）、百臂巨人（炎魔）、狼人（蝎尾狮）、金盏花（牛头怪）、成吉思 MK1「行星杀手」（成吉思）、库图佐夫（拿破仑）、万寿菊（谢尔曼）、恩奇都（德川）、珠穆朗玛与萨加玛塔（埃弗勒斯，人人可用），以及布莱（基德）、夹竹桃蛾（鬼面蛾）、哈布斯堡（萨拉丁）、火蜥蜴（狗头人）、史泰钦（米切尔）。
- **GMS**：核心奖励「超重挂载」（挂载点少于 3 个时获得超重型挂载点；有重型挂载点时必须占用它）、“暴风”充能刃、“飓风”集群投射器、武备冗余。
- **背景**：贵族后嗣、第二顺位者、连队扈从、潘克拉蒂、幼鹿（「随机」仍只掷规则书的 20 个背景）。
- **驾驶员装备**：个人动能屏障（装甲栏）。
- **扩展规则**：变体骨架、新标签「高效」、新状态「无形」，收录在术语库，并在用到它们的骨架下方显示「扩展规则说明」。

## 数据来源

- **数值**：`source/lancer-data/`，来自 COMP/CON 开源数据 [massif-press/lancer-data](https://github.com/massif-press/lancer-data)（核心规则书内容）。
- **中文（规则站）**：`source/tw/` 为 [Lancer 免费版繁中规则站](https://reno-lam.github.io/Lancer-Free-Version/) 原文，`source/cn/` 为其简体版。
- **中文（自译）**：规则站没有的部分（授权骨架、武器与系统效果、动作、可展开物、武器改装、标签说明等）放在 `source/i18n/zh/`。
- **v3.5 译名修订**：`source/core-v35-overrides.json`，对照表见 [TRANSLATION-V35.md](TRANSLATION-V35.md)。
- **扩展内容**：`source/expansions/all-expansions.js`（原文即中文）。
- **术语库**：手写术语在 `glossary.js`。

## 开发

修改数据或翻译后，重新生成 `data.js` 并运行检查：

```bash
node tools/build-data.js
node tools/test-rules.js
node tools/test-v35.js
```

| 命令 | 作用 |
|---|---|
| `node tools/build-data.js` | 合并数值、规则站译文、自译、v3.5 修订与扩展内容，生成 `data.js`（不要手改 data.js） |
| `node tools/test-rules.js` | 64 项回归检查：车卡规则、全部骨架与装备渲染、扩展机制、筛选器、术语匹配、武器表 |
| `node tools/test-v35.js` | 核心数据的 v3.5 译名、数值结构、稳定 ID 与旧术语残留（扩展条目会先剔除） |
| `node tools/extract-en.js` | 从 lancer-data 抽出界面会显示的英文到 `source/i18n/en/` |
| `node tools/i18n-missing.js [文件名] [条数]` | 列出还没翻译的条目 |
| `node tools/glossary-audit.js [术语] [条数]` | 列出术语在全部文字中的命中与上下文，检查有没有字面意义的误标 |

开发约定、文件结构与扩展内容的写法见 [CLAUDE.md](CLAUDE.md)。规则与译文的校准记录见 [VALIDATION.md](VALIDATION.md)，界面改进记录见 [UI-UX.md](UI-UX.md)。
