## 首轮改进（2026-10-21）

- **布局**：主内容使用明确的双栏布局，修正宽屏中空出一整列的问题；手机切换单栏，375px 下导航使用短标签。统一卡片间距、表单尺寸、对比度和键盘焦点提示。
- **操作层级**：顶部保留角色切换、新建和引导车卡，将导入、备份、复制和删除整理进「角色管理」。菜单支持 Esc 关闭。导航随滚动保留在顶部。
- **上下文**：每页显示用途说明和角色概要；GM 模式有明显提示及关闭入口，避免忘记关闭牌照限制。
- **保存反馈**：显示「已保存到此浏览器」；写入失败会提示导出备份，仍保留页面内的编辑内容。
- **天赋查找**：支持中文、英文名称和效果关键词搜索、只看已选、匹配数量、无结果提示和重置。筛选状态在本次使用中保留，不写入角色数据。
- **系统配置**：增加系统搜索；未选系统时禁用安装按钮，避免点击没有反馈。
- **防止误操作**：带有已装武器时切换骨架，先提示会清空挂载配置；取消会完整保留原配置。编辑器和引导模式都使用同一逻辑。
- **导出**：分为「分享与上桌」和「备份与继续编辑」，避免混淆图片与可编辑存档；长篇规则默认折叠，打印时自动展开。规则检查未通过时提供返回对应编辑页的快捷入口。
- **可访问性**：为主要表单和增减按钮补充可读名称；支持键盘下载预览卡片；修改数值后尽量保持原操作控件焦点；提供跳到编辑区的链接。
- **复制反馈**：剪贴板不可用或写入被拒绝时，展开文字角色卡并提供手动复制提示。

## 后续界面更新（至 2026-11-02）

- **骨架**：骨架筛选（名称、特征、厂商、定位、来源、只看可用）和骨架目录（先预览、确认后才改配装）；变体骨架显示所属标准骨架和实际制造商。
- **牌照**：等级成长页可展开「牌照内容」，查看 I–III 级解锁的骨架和装备；专业牌照单独取得。
- **查询工具**：术语库（正文术语高亮、悬停说明、点击跳转）、武器表（完整效果，其中的术语和标签可悬停）、规则 FAQ。
- **系统搜索**：除名称和效果外，也匹配系统类型和标签名，例如搜「可展开」能找到带可展开标签的系统。
- **核心奖励指定项**：招牌动作等需要指定对象的核心奖励在机甲页选择，未指定时规则检查会提示。
- **战斗地图**：新增「⑤ 战斗地图」，供 GM 在本机使用，与角色存档分开保存。
- **悬停说明修正**：「牌照内容」的装备原本只读 effect，131 件只有命中效果、多模式、动作或可展开物的装备悬停是空的，现改由 `itemHoverText()` 汇总；装备卡标题里的说明部分（动作类型、可展开物数值）恢复术语标记，名称仍不标；术语库层级高于武器表，点击武器表里的术语不会被挡住。
- **战斗地图占格**：单位大小 2、3、4 分别显示 3、7、12 格的占格（大小 4 按常见的截角三角），改大小立即更新，拖动与「移动到…」都预览整个占格；单位坐标为中心格。
- 回归检查现为 123 项（`node tools/test-rules.js`）。


## 当前交互补充（2026-11-04）

- **系统库**：与武器表并列，展示全部系统与武器改装；支持中英文、效果、标签、牌照和风味文本搜索，类别、类型、来源、动作、SP 和当前可用内容筛选，以及重置与无结果反馈。查询不会改变配装。
- **阅读层次**：装备规则与风味文本分开呈现，风味段落可展开阅读；保留原有术语高亮与悬停释义。未匹配段落不会用规则效果或相邻装备介绍填充。
- **模块次数**：装备卡和导出显示模块受限次数，计入适用的工程、核心奖励加成；查询库明确显示基础值。
- **规则措辞**：盾牌阵列无人机的反应明确为先于触发攻击结算，移动完成后继续结算攻击；模块与独特标签区分单件武器和整台机甲的安装限制。
- **重分配**：天赋、牌照及核心奖励支持分别重置，提供撤销；取消不会更改角色。界面提供操作便利，逐级重分配资格仍由参与者按规则确认。
- **文档入口**：说明集中在 `docs/`，项目首页链接到对应译名和风味缺项表。整理不会更改车卡器存档位置。
