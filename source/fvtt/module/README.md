# LANCER 中文（lancer-cn）

Foundry VTT 模组：LANCER 系统（v3.1.3，Foundry v13）界面的简体中文翻译，并为中文名骨架补上骨架插图，另提供攻击时选目标、机甲核心协议（CP）全骨架自动化、武器与改装特效自动化、科技与入侵系统隔离结算、全 50 项驾驶员天赋与常用战斗核心奖励自动化、自动挂异常与撤销、一键豁免检定与减半联动、非攻击卡掷伤害与范围模板、跨权限护甲抗性伤害结算与预览、基础动作、受限计数、回合结束清异常提醒、掩护区、困难与危险地形、六边形墙体、导入车卡器战斗地图、指示物名字与飘字等战斗辅助工具。由[简易车卡器](https://deepdream-cs.github.io/-Lancer-/)项目维护。

## 安装

在 Foundry 的「附加模组 → 安装模组」底部「清单链接」中填入：

```
https://deepdream-cs.github.io/-Lancer-/dist/fvtt/lancer-cn/module.json
```

也可以把 `lancer-cn` 文件夹直接放进 Foundry 用户数据的 `Data/modules/`（得到 `Data/modules/lancer-cn/module.json`）。

安装后在世界里启用模组，并在「游戏设置 → 配置设置 → 核心 → 语言」中选「中文」。语言是每个浏览器各自的设置，玩家也要各自切换。模组更新后请**重启 Foundry**：新增的模组设置、区域行为与 socket 只在启动时载入。

- 需要 Foundry v13 与 LANCER 系统 v3.1.3（该系统版本不支持 Foundry v14）。
- 本模组只翻译 LANCER 系统自己的界面文字。Foundry 核心界面的中文请另装核心翻译模组 fvtt-cn 的 foundry_chn（同样使用语言代码 `cn`）；Foundry v13 要用 13.350 版：`https://github.com/fvtt-cn/foundry_chn/releases/download/13.350/module.json`。
- 骨架、装备、天赋、NPC 等内容的中文来自简易车卡器导出的内容包 `lancer-cn-core.lcp` 与 `lancer-cn-expansions.lcp`，在系统的内容包管理器中于英文核心数据与官方补充书**之后**导入。之后若再导入英文核心数据，核心条目会变回英文，需要再导入一次中文核心包。
- 详细步骤与常见问题见简易车卡器的 [Foundry 内容包说明](https://github.com/DeepDream-CS/-Lancer-/blob/main/docs/FVTT-LCP.md)。

## 界面

- **界面翻译**：角色表、聊天卡、设置项、状态图标名称、结构 / 过热表等 427 条，术语与车卡器及内容包一致。结构与过热表的文字依核心规则书 v3.5 第 75–76 页。
- **写死的英文**：系统模板和代码里不经语言文件的约 680 段文字（表头、挂载点选项、命中与伤害面板、扫描卡、提示消息、对话框等），在界面语言为中文时按词典显示为中文。只改显示，不改输入框、编辑区和存档数据。开发调试用的错误信息保留英文。
- **中文版面修正**：伤害面板的伤害类型下拉框按中文收窄，数值框不再被挤成「1(」；「会心 / 命中 / 未命中」不换行；目标名两侧的装饰箭头换成中文字体也有的 ▸ / ◂（原来显示成方框）。
- **骨架插图**：LANCER 系统按骨架英文名查找 Retrograde Minis 插图，骨架改成中文名后会找不到。本模组改按骨架 id 查找：
  - 新建或导入骨架条目时补上插图；
  - 把骨架拖到机甲上后，若机甲头像和指示物仍是系统默认图片，换成该骨架的插图。玩家自己设置的图片不会被替换；
  - 车卡器扩展中的变体骨架沿用原骨架插图；没有官方插图的扩展骨架保持默认图标。

## 战斗工具

- **攻击时选目标**：开始攻击、科技攻击时，准度面板左边会弹出目标面板。
  - 按敌方 / 中立 / 友方列出场上的指示物，按距离排序，并标出是否在武器射程（科技攻击为感应）内。距离按双方所占格子最近的一格计算，只作提示，不阻止选射程外的目标。
  - 点一行就是锁定 / 取消锁定，可多选；面板开着时，左键点地图上的指示物也是锁定 / 取消锁定（自己的指示物照常选中）。
  - 开始新攻击时，如果锁定的还是上一次攻击的目标，会先清掉（列表里标着「上次」，点一下就能再选）；射程内只有一个敌人时自动选上。
  - 单独掷伤害时也会弹出；从攻击卡掷伤害时目标已定，不弹出。

    - **冲撞**（快速动作）与**权宜攻击**（完整动作）：近战攻击，目标面板按「邻接」标射程。冲撞命中后自动挂「伏卧」；权宜攻击掷伤害时预填 1d6 动能。
    - **躲藏**（快速动作）与**搜索**（快速动作）：躲藏为自身挂上「匿迹」；搜索在锁定目标时发起「系统 vs 敏捷」对抗检定卡，胜出后自动解除目标的「匿迹」（未锁定目标时单掷系统检定，方便侦测隐藏地雷）。
    - **受身**（反应，1/轮）：自动开启全部五种伤害抗性，卡片附**「关闭受身抗性」**按钮，并在该角色下一回合开始时自动发出仅限 1 个快速动作的提醒卡。
    - **起身**（代替移动）：未处于「固定」时解除「伏卧」（固定时提示禁止起身）。
    - **脱离**（完整动作）与**准备**（快速动作）：脱离发送本回合移动无视交战与反应的声明卡；准备弹窗录入触发条件与准备的快速动作留底。
    - **关机**（快速动作）与**开机**（完整动作）：关机自动将热度归零，清除「暴露」「超温危域」「锁定」，并挂上「关机」与「晕眩」（关机期间回合结束提醒不会清掉晕眩）；开机一键解除「关机」与「晕眩」。
    - **自爆**（快速动作）、**弃机**（快速动作）与**上下马**（完整动作）：自爆倒计时卡自动提供「放置爆发 2 模板」「敏捷豁免（成功减半）」与「掷 4d6 爆炸伤害」按钮；弃机为机甲挂上「受损」并将驾驶员设为下马；上下马切换驾驶员乘坐状态。
  - **NPC**（核心规则书 v3.5 第 272–273 页）：
    - **入侵**（快速科技，命中自动「受损」）、**锁定**、**擒拿**（同样支持后续挣脱 / 争抢主导 / 结束擒拿）、**冲撞**、**躲藏**、**搜索**（锁定目标时同样生成系统 vs 敏捷对抗检定卡）、**权宜攻击**（按层级预填 3/4/6 动能）、**稳住阵脚**（热度归零、清除暴露、填装所有未填装的装填武器），另共享**挣脱擒拿**、**起身**、**脱离**、**准备**。
  - **步战驾驶员**（核心规则书 v3.5 第 73–75 页）：
    - **骑乘**（完整动作）：锁定邻接敌方机甲，选适用技能触发或毅力发起对抗检定（敌方机甲在卡上自选机体或敏捷应战）；胜出自动生成骑乘控制卡，含**「干扰（受损+缓慢）」「扯断管线（+2 热度）」「破坏（4 动能）」**三选一按钮、机甲**「甩脱（机体/敏捷）」**对抗检定按钮与「结束骑乘」按钮。
    - **包扎**（完整动作）：对自己或锁定的邻接驾驶员掷技能触发 / 毅力检定 **10+**（身上有「止血贴」或「修复胶」时也可选择直接消耗次数），自动为清醒伤员回复一半最大 HP，或以 **1 HP** 唤醒处于「昏迷」的驾驶员（驾驶员 HP 归零时会自动挂上「昏迷」）。
    - **装填**（快速动作，装填身上未装填的驾驶员装填武器）、**躲藏**、**搜索**（射程 5 内对抗匿迹目标敏捷），另共享**起身**、**脱离**、**准备**、**上下马**。
  - 处于「晕眩」的机甲在机体与敏捷对抗检定中按规则自动失败。这些按钮不扣动作栏里的动作次数。
- **受限次数**：
  - **掷骰式受限**：原型武器 I / II（受限 1d6+2）、III（受限 2d6），系统原本当成 1 次。现在「USES」格子旁有「掷 1d6+2」按钮，按掷出的结果（加上机甲的受限加值）显示格子；全面维修后自动重掷。还没掷过时没有格子，系统也不会因次数用完而阻止攻击。
  - **文字里的受限**：骨架核心系统、系统动作等只在说明里写「受限 3」的，Foundry 没有次数栏。机甲表「装配」页会多一张「受限次数」卡片，点格子扣减或恢复，全面维修后回满，也可以按「全部回满」。目前有孙子「霎间锚点」、哈布斯堡「E-R-桥塔」、八角「建筑项目」、“洞察”原型思维体、“诡术师”干扰套组。
- **说明里的骰子可以点**：系统、武器、天赋等说明文字中的「1d6」「1d6+2」变成带骰子图标的链接，点击后以该角色的名义掷骰并发到聊天（例如定制涂装作业的「掷1d6」）。伤害栏和编辑中的文字不变。
- **自动挂异常、撤销状态与手动补挂**：
  - 攻击命中、会心一击或发起带状态的机甲 / NPC 基础动作（冲撞、破碎讯号、NPC 入侵）时，自动按目标命中结果施加无豁免前提的状态；攻击消耗了目标的「锁定」时，即使目标不属于当前玩家也会经在线 GM 自动移除锁定。
  - 使用带明确自身增益或抗性的系统 / 动作（如全伤害抗性、单项抗性、隐形、无形、匿迹、飞行、支援）时自动挂给自己；针对盟友或有条件选择的增益列为手动按钮。
  - 每次自动挂状态都会在聊天卡下方显示「已自动施加：……」与**「↩ 撤销状态」**小按钮，误判时一键回退（只移除本卡新挂上的状态，不会误删目标原本已有的状态）；带条件或需手动补挂的状态仍保留手动按钮。
- **一键豁免检定与减半联动**：
  - 武器、系统、动作或特性文字含「机体 / 敏捷 / 系统 / 工程豁免」时，自动读取发起者的豁免目标（DC）并在聊天卡下方生成所有人可见的豁免按钮，方便被攻击的玩家直接在 GM 的 NPC 卡片上点击掷豁免。
  - 检定完成后自动发送通过 / 失败结果卡：失败时自动挂上对应异常（同样附「↩ 撤销状态」）；若文本含「成功减半 / 成功受到一半伤害」，后续从该卡点击「掷伤害」时，已通过豁免的目标会自动设为伤害减半。
- **非攻击卡掷伤害与范围模板**：
  - 手雷、地雷、核心系统、NPC 特性等非攻击聊天卡若写明角色伤害（含骰子、固定值、NPC 按层级 `a/b/c` 数值及穿甲，自动跳过纯物件/地形破坏句），卡片下方提供**「掷伤害」**按钮，直接调用系统的伤害流程。
  - 带溅射（Blast）、爆发（Burst）、线形（Line）、锥形（Cone）范围的武器或系统，在目标面板顶部与聊天卡下方提供一键**放置范围模板**按钮，放下后自动锁定模板内的指示物。
- **跨权限护甲 / 抗性伤害结算与结算预览**：
  - 玩家对非自己拥有的敌方 NPC 点击伤害卡上的原生「应用伤害」或「撤销」按钮时，由在线 GM 自动代算护甲、穿甲、离散、暴露翻倍、五种抗性、过载护盾并扣减或回退 HP / 热度 / 燃烧（原本系统会因权限不足无反应）。
  - 伤害卡每个目标行下方实时显示中文**「结算预览」**（含暴露 ×2、护甲减免、抗性减半、过载护盾抵扣及最终 HP / 热度 / 燃烧变化），切换倍率下拉框时实时更新。
- **流程补完、自动超温危域、回合结束提醒与抗性开关栏**：
  - **NPC「致命 / 额外致命」暴击加伤**：拥有核心包「致命」（+1d6）或超体「额外致命」（T2 +2d6、T3 +3d6）的 NPC 会心命中时，自动掷出额外暴击伤害并只计入会心目标。
  - **机甲「稳住阵脚」清状况**：选择清除自身或邻接角色状况时，若只有 1 项状况则自动清除，有多项时弹窗点选，并同步更新聊天卡文字。
  - **结构 / 过热表与数值状态**：掷出结构伤害表或过热表结果时自动挂上对应状态（失能、晕眩、受损、暴露，怪形含缓慢、伏卧），并修复系统原本 1 压力上限 NPC 过热后未扣除热度上限的问题；角色热度达到上限一半时自动挂上「超温危域」（低于一半时解除），无结构上限或结构已归零的单位 HP 归零时自动挂上「失能」。
  - **回合结束清异常提醒**：战斗轮次推进时，若刚结束回合的角色身上有常见的持续至回合结束的状态（受损、缓慢、固定、受扰、离散、晕眩、支援、隐形、无形、五种抗性；保留锁定与伏卧，不做交战检测），在聊天栏发出提醒卡，可逐项点击清除（误点再点恢复）或一键「全部清除」。
  - **抗性开关栏**：机甲表「装配」页与 NPC 表主页新增「抗性开关」栏，一键切换动能 / 能量 / 爆炸 / 热度 / 燃烧单项抗性或全抗性。
- **掩护区**：
  - 在左侧「区域」工具栏选「软性掩护格」或「硬性掩护格」（GM），点击格子把整格加入本场景的软性 / 硬性掩护区（所有人可见，蓝色为软性、橙色为硬性），再点移除，按住拖动可连续操作。也可以自己画任意区域，在「行为」中新增「LANCER 掩护区」。
  - 指示物进入区域时自动获得「掩护 - 软性 / 硬性」状态，离开时去掉；同时在多个掩护区里取最高的掩护。画好或启用区域时，已经在里面的指示物也会获得掩护。手动给目标加的掩护状态，在它离开掩护区时会一起去掉。
  - 攻击时命中面板会按目标身上的掩护自动计入 -1 / -2；导引武器、科技攻击和非投掷近战按规则忽略掩护。
- **困难地形与危险地形**（GM）：
  - 在左侧「区域」工具栏选「困难地形格」（橄榄绿）或「危险地形格」（红色），点击格子加入对应区域，再点移除，按住拖动可连续操作。
  - **困难地形格**：使用 Foundry v13 的移动消耗修正（步行每空间消耗 2 点移动力；LANCER 系统的飞行与「无视地形」移动方式仍按每空间 1 点计算）。
  - **危险地形格**：带「LANCER 危险地形」区域行为（也可在自绘区域中手动添加，配置失败伤害与动能 / 能量 / 爆炸 / 燃烧 / 热度类型，默认 5 点动能）。指示物移入区域或在区域内结束回合时，向聊天发送提醒卡，并附一键「工程检定」按钮（每轮是否已触发过由 GM 与玩家判断）。
- **六边形墙体**（GM）：在左侧「墙壁」工具栏选「六边形墙体」，点击格子放置一整格不可通过的墙体，再点一次移除，按住拖动可连续放置或连续移除。
  - 每格墙体由 6 段阻挡移动的墙和一个所有人都看得到的深色六边形组成。点只剩六边形的格子也能删掉它；用 Foundry 自带的墙壁工具删光一格的墙时，六边形会一起删掉。
  - 默认不阻挡视线，可在模组设置「六边形墙体阻挡视线」中开启（只影响之后放置的墙体）。墙体不提供掩护，掩护请手动设置或画掩护区。

- **指示物名字**：放上地图的指示物默认始终显示名字（所有人可见）。可在模组设置「指示物显示名字」改成「鼠标悬停时显示」或「不改」；第一次启用模组或修改这项设置时，各场景里已放好的指示物也会一起改。
- **飘字**：
  - 施加伤害、热度等时，指示物上会飘出「-5 HP」「+2 热度」「-1 结构」，所有人都看得到。这是 LANCER 系统的「浮动伤害数字」，默认关闭，模组在每位玩家第一次载入时替他们打开一次；不想要可在「系统设置」里关掉。
  - 加上 / 去掉状态时飘出黄色的「+ 缓慢」或灰色的「- 缓慢」。

## 车卡器资料

GM 在「配置设置 → 模组设置 → LANCER 中文」中点「导入车卡器资料」：

- 在 LANCER 的驾驶员物品合集包中建立 21 张专业牌照。专业牌照装备随扩展内容包导入，牌照表会按等级列出；拖到驾驶员身上时，牌照等级默认为该牌照的等级。Foundry 不检查专业牌照的取得条件。
- 把骨架牌照改为骨架的中文名（系统导入内容包时只新建牌照、不更新名称）。
- 生成「车卡器资料」日志合集包：专业牌照规则与 21 张牌照的说明及装备链接，扩展厂商 C&H、K/KCA、PI-OF 的说明与骨架。

请在导入两个中文内容包之后运行；可以重复运行，日志会重新生成。

## 导入车卡器战斗地图

GM 在侧栏「场景」顶部的**「导入车卡器地图」**按钮（或在「模组设置 → LANCER 中文 → 导入车卡器地图」）中选择车卡器导出的地图 JSON（同时兼容「导出地图」的 `Lancer-战斗地图.json` 与「导出到 Foundry」的 `*-foundry.json`）：

- **新建独立六角格场景**：按车卡器当前可见范围自动建立平顶六角格场景（自动匹配奇数列 / 偶数列下移，关闭迷雾与指示物视野，开启全局照明），写入障碍物（六边形墙体）、软/硬掩护区、困难/危险地形区、涂色格、文字标注、画线，以及单位的底层「部署位置标记」图形（不生成无角色的空白指示物）。
- **铺到当前场景**：保留当前场景已有的背景底图、光照和指示物，对齐当前场景网格写入地形与标记；重复导入时可自动替换上次导入的车卡器内容，已有的手动掩护格会合并保留。
- 摆好真正的机甲 / NPC 指示物后，可再次打开「导入车卡器地图」弹窗点**「清除部署标记」**一键移除底层的单位位置圆标。
