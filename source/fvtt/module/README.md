# LANCER 中文（lancer-cn）

Foundry VTT 模组：LANCER 系统（v3.1.3，Foundry v13）界面的简体中文翻译，并为中文名骨架补上骨架插图。由[简易车卡器](https://deepdream-cs.github.io/-Lancer-/)项目维护。

## 安装

在 Foundry 的「附加模组 → 安装模组」底部「清单链接」中填入：

```
https://deepdream-cs.github.io/-Lancer-/dist/fvtt/lancer-cn/module.json
```

安装后在世界里启用模组，并在「游戏设置 → 配置设置 → 语言」中选「中文」。

- 本模组只翻译 LANCER 系统自己的界面文字。Foundry 核心界面的中文请另装核心翻译模组（例如 fvtt-cn 的 foundry_chn，它同样使用语言代码 `cn`）。
- 骨架、装备、天赋等内容的中文来自简易车卡器导出的内容包 `lancer-cn-core.lcp` 与 `lancer-cn-expansions.lcp`，在系统设置的内容包管理器中导入。

## 内容

- 界面翻译：角色表、聊天卡、设置项、状态图标名称、结构 / 过热表等 427 条，术语与车卡器及内容包一致。结构与过热表的文字依核心规则书 v3.5 第 75–76 页。
- 骨架插图：LANCER 系统按骨架英文名查找 Retrograde Minis 插图，骨架改成中文名后会找不到。本模组改按骨架 id 查找：
  - 新建或导入骨架条目时补上插图；
  - 把骨架拖到机甲上后，若机甲头像和指示物仍是系统默认图片，换成该骨架的插图。玩家自己设置的图片不会被替换。
  - 车卡器扩展中的变体骨架沿用原骨架插图；没有官方插图的扩展骨架保持默认图标。

- 写死的英文：系统模板和代码里不经语言文件的约 670 段文字（表头、挂载点选项、命中与伤害面板、扫描卡、提示消息、对话框等），在界面语言为中文时按词典显示为中文。只改显示，不改输入框、编辑区和存档数据。开发调试用的错误信息保留英文。
- 车卡器资料（GM 在「配置设置 → 模组设置 → LANCER 中文」中点「导入车卡器资料」）：
  - 在 LANCER 的驾驶员物品合集包中建立 21 张专业牌照。专业牌照装备随扩展内容包导入，牌照表会按等级列出；拖到驾驶员身上时，牌照等级默认为该牌照的等级。Foundry 不检查专业牌照的取得条件。
  - 把骨架牌照改为骨架的中文名（系统导入内容包时只新建牌照、不更新名称）。
  - 生成「车卡器资料」日志合集包：专业牌照规则与 21 张牌照的说明及装备链接，扩展厂商 C&H、K/KCA、PI-OF 的说明与骨架。
  - 请在导入两个中文内容包之后运行；可以重复运行，日志会重新生成。
