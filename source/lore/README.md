# 装备风味文本

[项目说明](../../README.md) · [文档目录](../../docs/README.md) · [当前核对表](../../docs/EQUIPMENT-LORE-AUDIT.md)

更新日期：2026-11-04。所有命令从项目根目录执行。

## 数据与来源

`zh.json` 按装备稳定 ID 保存中文风味文本、资料名称和 PDF 页码。来源为用户本地核心规则书及扩展 PDF；缺少已匹配中译的核心条目按 COMP/CON 原始英文描述翻译，来源字段已标明。GMS 武器沿用上游为对应条目提供的系列共用介绍。

当前生成结果含 477 项中文，0 项仅英文，41 项尚未可靠匹配独立风味文本。数量以生成后的核对表为准，武器、系统与模块均参与核对。

## 构建与检查

```bash
node tools/build-data.js
node tools/test-equipment-lore.js
```

完整构建先生成 `assets/js/data.js`，再生成独立的 `assets/js/equipment-lore.js` 和 `docs/EQUIPMENT-LORE-AUDIT.md`。仅修改风味段落且规则数据未变时，也可以运行 `node tools/build-equipment-lore.js`。脚本会创建 `docs/`；不要手改生成文件或把核对表重新放回根目录。

## 补录约定

缺项表示当前尚未可靠匹配独立风味段落，不表示原书一定没有。天赋装备的“由某天赋获得”等获取说明不作为风味文本；不以规则效果、相邻装备或牌照总介绍替代缺失段落。

补录时核对稳定 ID、条目标题、整段内容、资料名称及页码，避免串到相邻装备。规则效果仍在原有规则源中维护，风味文本不参与数值计算。

网页在装备规则、武器表和系统库中展示可展开的风味段落；系统库可检索这些文本。提交时同时包含中文源数据、独立生成数据和核对表；无需打包用户本地原 PDF。
